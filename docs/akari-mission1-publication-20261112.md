# 第1ミッション オンライン公開承認

2026-11-12、ユーザーが次を明示的に承認した。

- この試遊ページだけを、ログイン不要でURLを知る人が閲覧・試遊できる設定へ変更する。
- 公開対象は第1ミッションだけ。検索エンジンへの登録は行わず、編集権限は公開しない。
- Draft PR #35を維持。mainマージ、本番ゲームへの反映は禁止。
- 公開後にログアウト状態で開始からクリアまで確認する。

## 公開用の境界

従来の配布HTMLには第2ミッション以降へ進める導線が残っていたため、
オンライン公開用の成果物だけを第1ミッションに限定する。
制作ソースの `games/akari/game.js`、理科判定、通常の14ミッション版は変更しない。

`scripts/akari-mission1-trial.mjs` は既存エンジンの初期ミッションを1に限定し、
ミッション移動を1以外では受け付けない。クリア後は第1ミッションの再試遊へ戻る。
メニューには第1ミッションだけを生成し、公開用のHUDから移動メニューを外す。
専用のv2セーブ領域を使い、通常版のセーブを変更しない。
オンラインHTMLと、そのページから取得できるHTMLは同じ第1ミッション限定版。
変更元のコードが一致しなければビルドを停止する。

公開先：`https://akari-mission1-review-20261112.jyoker.chatgpt.site/`
既存Site ID：`appgprj_6af57549b0188191bfdc774af865f165`

## 検証

匿名HTTPで認証画面ではなく、生成したHTMLとSHA-256が一致することを要求する。
Chromium/WebKitの320/390/1440pxを、それぞれCookieなしの新規コンテキストで開始する。
配線、点灯、切断、短絡、理由問題、クリア、再読み込み、再試遊を確認する。
メニューから第2ミッション以降へ進めず、過去の進行位置があっても1へ戻ることを確認する。
編集者の許可リストは変更しない。`noindex,nofollow` とrobots.txtを維持する。

公開と検証の最終結果はPR #35の本文に記録する。今回の公開承認を、
デザイン承認・全ミッションへの展開承認・mainへのマージ承認と解釈しない。
