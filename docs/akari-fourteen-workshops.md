基点は PR #38 の d57c3ec。通常版と第1試遊ページは独立している。統合候補は node scripts/build-akari-workshops.mjs で生成する artifacts/akari-fourteen.html。画像、書体、コードを同梱する。既存公開ページへデプロイするジョブは追加していない。

## ミッションごとの設計判断

|面・場所|従来の画面と操作、つまずきやすい点|維持する科学判定・学習目標|統合候補での操作と発見|
|---|---|---|---|
|1 村の街灯|木の実験台で4端子を配線。電池の両極だけを結ぶこともできる|電球を通る閉回路。短絡を優先|承認済みのドラッグ・2点タップと未配線の輪を継承。自分の線を切って戻せる|
|2 切れた通り道|1本接続済みの回路を見て修理する|切れ目を修理し、別の図でも点灯を予想|共通の端子と木製台。どこに1本足すか考える|

|6 時計塔|部品点検後に別の配線盤で組み直す。最初は文章が多い|断線を診断し、電池＋から電球を経て−まで実際の経路を示す|点検の根拠は残し、組立盤に実物調の電池・電球。危険な直結は修理まで表示|
|7 時計塔の合図|スイッチの図と操作ボタンが分離|直列の2スイッチは両方ONのとき点灯|図中のレバーを押し、配線した回路の4通りの結果を観察|
|8 港の合図|並列分岐を図とカードで照合する|どちらかの枝が通れば点灯。スイッチを通らない近道を区別|港の舞台と同じ実験道具で、分岐を配線してレバーを切り替える|
|9 電池の大きさ|大きさ・使用時間を選択して検証する|同種・同じ公称電圧の電池を同条件で比較。長時間後の差はこのゲームの設定|電池本体を押して大きさを切替。点灯直後と長時間後の記録から判断|
|10 ふたつの力|電池の本数・電球の定格を操作。定格表示を見落としやすい|直列電圧と定格を照合。定格超過は危険判定|電池部分を押して本数を変える。定格・結果の表示を併読する|
|11 電池の向き|電池の向きを選択肢で変更|1個を逆にしても豆電球は点灯。同電圧2個を逆向き直列にすると起電力が打ち消し合う|電池を押すと極の向きも変わる。向きと電池数を独立に比較|
|12 危険な近道|A〜Eの導線と下の修理一覧を往復|電球を通らず両極を結ぶすべての道を外し、点灯経路を残す|図中の導線ラベルを直接押して脱着。仮想通電して確認|

|14 灯台の復旧|3検査台、設置、転移課題、最後の配線と工程が長い|電池の向き・導体・球の横と底の組合せ。さらにON/OFFを正しく配線|図の検査箇所から該当する台を選び、材料と向きを変えて再測定。最後に配線して経路を示す|

## 表示・操作の共通設計

実験エンジンが点灯・消灯・短絡・定格超過を判定する。表示側の workshops.js はその結果と既存ボタンの操作を利用する。新しい図上操作は有効な操作だけに対応し、キーボード用の元ボタンも残す。試行回数や予想の的中を新しい得点条件にしない。第1〜3は既存のハサミ、スナップ、炎の継続表示と減モーション設定を継承。後半の短絡演出は接続中の配線盤、または実際に仮想通電した結果に対応する。炎は発熱・発火の危険の表現。児童は実物の電池で短絡実験を行わない。

庭・塔・港・博物館は既存の村の夕景を参照して生成した原画から切り出し、灯台は専用原画を使用。配布は縮小WebP。前半の乾電池・豆電球・木目・炎素材と、同梱ライセンス付き書体を再使用。素材追加に伴う第三者サイトからの画像読み込みなし。消音切替は既存の音声設定を使う。

## 検証方法と残課題

Village workshop review は新規ブラウザで第1〜14を順番に操作し、各面の実際のクリア保存を検査する。ステージ解放用セーブの注入は行わない。実験結果はモデル試験、操作の到達性はPlaywrightで別々に確認する。途中の誤予想・誤答・修理のやり直しを含む。ベースラインの対照画像は第1〜3がリアル版のPR #38。通常デザインの公開版とは異なる。詳細な実行状況と試遊資料はDraft PR #39を参照。

実機iPad Safari・iPhone Safariと児童の初見試遊は未実施。横長の大型回路図は内側で左右に移動できる設計。すべての説明や記録が1画面に入るわけではない。図上の補助操作はSVGの縮尺に従うので、タブレットで押しやすいかの実機評価が必要。実機での描画速度・音・タッチの遅延は未計測。第6の初期診断、第10の定格、第14の長い理由選択は児童観察を優先する。授業では電気を通す物と通り道が基礎であり、定格・複数電池・複数スイッチは発展課題として扱う。
