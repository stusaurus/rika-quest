## 遊びと科学的な判定

1. 暗い村と実験台の切れ目を調べると、同じ場所を指す短いメモが残る。
2. 鉄のクリップ、アルミ板、乾いた木、プラスチックを村で見つける。発見した材料は常時見える右側の置き場へ入る。
3. 「つく／つかない」を予想し、材料をそのままドラッグしてはめる。タップで選択・配置する代替操作もある。
4. 両方の接点がつながり、材料が電気を通すと、その場で電球と村が点灯する。「ためす」ボタンは使わない。
5. 電気を通す材料と通さない材料を少なくとも1種類ずつ実験し、記録を比較する。
6. 比較した実験に合う理由を選び、試した導電性材料で回路を復旧してクリアする。

比較する変数を材料1つにそろえるため、主な修理箇所は切れ目1か所に整理した。金属でも接点が片側だけ、線が切れている、電球を通らない短絡がある場合は消灯する。材料の性質を示す記録は、両接点と基準の配線がそろった実験だけを残す。配線不足を「金属が電気を通さない」と誤記録しない。

乾いた木、通常のプラスチック、表面を塗装していない鉄・アルミを、1.5V乾電池と豆電球で比べる教材上の条件である。材料の予想が外れても減点しない。理由の誤答でクリアすることはできず、案内は実際に試した材料を参照する。

導線の描画、なぞって切る操作、ハサミ、短絡の警告と画像演出を維持した。材料を線で迂回して点灯させただけでは「材料で修復した」ことにせず、クリア条件を満たさない。

## 美術と画面

承認済みの村の画風、乾電池、豆電球、木製実験台、真ちゅうと深い緑のHUDを継承。第3専用に街灯周辺の消灯・復旧の背景2枚と材料4点を制作した。材料は発見時・持ち運び・置き場・取り付け後に同じ画像を使い、縦横比を保つ。制作プロンプトと方式は `games/akari/assets/mission3/art-prompts.json` に記録した。

PCは左にメモ、中央に回路、右に材料。狭いスマホではメモを回路の直下へ移し、材料置き場と実験を同時に見られる。予想は短い2択、理由は実験後に画面下へ出す。巨大な重ねパネルは使わない。

最終スクリーンショットを2ブラウザ・全画面幅で目視確認した。横はみ出し0px、材料欄による実験画面の遮蔽なし、接点とSVGの座標誤差は最大0.0219px未満、操作対象は44px以上。短い画面では理由や手帳まで縦スクロールする。
