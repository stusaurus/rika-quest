# あかりクエスト｜第1〜第3ミッション 初見試遊計画（2026-11-19）

> 対象：PR #38（`review/akari-first-three-polish`）。この文書は**試遊前の計画・記録用**であり、児童での検証結果ではありません。PRはDraftのまま維持し、本番公開・mainマージは行いません。

## 目的と確認する問い

自動操作で確認済みの「完走できる」「画面がはみ出さない」に加えて、小学3年生が**説明を読まずに始められるか／迷ったときに画面から手掛かりを見つけられるか／科学的に理解できるか／また遊びたいか**を確かめる。

特に、修正した見た目とクリック・タップ可能な場所が一致しているかを観察する。

## 実施条件

- 対象：可能なら初見の児童3〜5人。保護者・学校の必要な同意を取り、授業や評価に影響しない任意参加にする。
- 機材：普段授業で使うiPadを優先。実機Safariの環境・画面向き・OSを記録。必要ならPCを別枠として観察する。
- 1人ずつ、原則10〜15分程度。進捗は記録するが時間制限をクリア条件にはしない。
- 遊び方の説明は最小限。「まず、自分で進めてみてね。わからないときは、考えていることを言ってね」で開始する。
- 観察者は先回りして指ささず、最初のつまずき位置を記録する。操作不能・長時間の停止時のみ補助し、補助した事実を記録する。
- 児童の氏名・顔写真・音声・個人情報は保存しない。IDは P01 等の匿名コードとし、公開リポジトリやPRに個人情報を書かない。
- 現行PR上のレビュー用成果物を利用する。main・既存公開版を変更しない。

## 観察する行動（各ミッション）

| 段階 | 自力でできるか確認 | つまずきの兆候 | 記録すること |
|---|---|---|---|
| M1 配線 | 4端子から2点を選び導線を描く。未接続の金色点線に気づく | 点線を押せない装飾と誤認、同じ端子を連打 | 初回操作、完成までの試行、補助回数 |
| M2 修理 | 既存の線と未接続の端子を見分け、必要な線だけを追加 | 既存線を消す、線が不足する場所がわからない | 見つけた端子、誤操作、説明依存 |
| M3 発見 | 導線の切れ目と虫眼鏡に気づいて調べる | ラベルだけを押す、切れ目が見えない | 発見までの手順、正しく押せたか |
| M3 実験 | 材料を両端に接触させ、2種以上を比較し、点灯/不点灯を記録する | 片側接触の消灯を絶縁体と誤認、ドラッグが困難 | 材料ごとの操作、比較、誤概念 |
| M3 説明 | 「金属が電気を通す」だけでなく、回路が一周つながる必要を説明できる | 明るさだけを判断、選択肢の丸暗記 | 児童の自発的な説明（匿名・短い要約） |
| 全体 | 終了後に「もう一度遊びたいか」を自分の言葉で答える | 疲れる、操作目的が不明 | 率直な反応と理由 |

## 補助と判定

各ステップの到達を次の4段階で記録する。

- **A 自力**：説明も指差しもなく達成
- **B 中立的な問い**：「今どこが気になる？」等、操作箇所を示さず達成
- **C 具体的なヒント**：対象を言葉や指差しで示して達成
- **D 未達**：補助しても進めない／試遊を中断

「自力」の評価では、B以上を成功として数えない。児童が実験内容を理解したかどうかと、操作だけできたかどうかは別に記録する。

目安：同じ場所で2人以上が C/D になったら優先修正候補。人数が少ないため成功率に統計的な意味を過剰に持たせず、原因と具体的な場面を優先する。

## 試遊後の判断

1. まず操作不能・押す場所の誤認・実験結果に関する誤解を最優先で分類する。
2. 次に、同じ箇所で繰り返すつまずきの原因が**配置・文言・操作反応・学習上の難しさ**のどれかを分ける。
3. 修正はPR #38からの独立したDraft作業で行い、変更前後の同一場面画像とChromium/WebKitの回帰テストを残す。
4. iPad実機の確認結果は自動試験と別欄に記す。児童試遊が未実施なら「未実施」と明記し続ける。
