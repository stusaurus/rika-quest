## ステージ1「ねむれる磁力の門」— Draft試作

1. 光る検査器を棒磁石に沿ってドラッグし、5か所の反応を調べる。左右の端・中央の3か所以上の結果を比較する。ボタンやキーボードでも操作できる。
2. 棒磁石の両端に鉄片が集まることから磁極の存在を発見する。
3. N極が既知の赤い基準磁石をドラッグし、印がない棒磁石の左右へ近づける。引力・反発の違いを視覚と文章で確認して極を同定する。
4. N極の印がある門へ、操作磁石を直接ドラッグして近づける。極はN/Sから選択でき、距離はドラッグまたはスライダーで設定できる。
5. 観察→発見→応用を経てステージクリア。ブラウザ内のセーブ・リセット対応。

**正答だけで進行しない仕組み**：棒磁石の観察3地点、基準磁石での左右実験を必須にする。誤答は実験結果の見直しを促す。

**科学的な注意**：場面内の鉄片反応を1/3/5の便宜的な強弱で描く。実測値ではない。門の「3cm以下で解錠」もゲーム内ルールであって磁石の一般的性質ではない。実際の磁力は磁石・距離・条件による。棒磁石の端は一般に強いが、磁石の形状によって極の位置は異なる。

## 実装

- `games/magnet/index.html`: 単体で動作するゲーム画面。外部のアート・CDNは読み込まない。
- `games/magnet/engine.mjs`: 純粋関数の教育モデル（UIと分離）。
- `games/magnet/interaction.mjs`: SVG座標と実験位置・距離の純粋な変換関数。
- `scripts/check-magnet.mjs`: 科学ルール・DOM要件・JavaScript構文チェック。
- `tests/magnet-stage1.mjs`: Playwright Chromiumによるボタン/スライダー操作の通しプレイ（320・390・430・1440px）。
- `tests/magnet-gestures.mjs`: 320pxマウスドラッグ＋390pxモバイルタッチイベント（Chrome DevTools Protocol）での全ステップ通しプレイ。鉄片の反応表示、N/Sの選択、再読み込み保存を検査。
- `tests/magnet-public-preview.mjs`: HTTPSの外部試遊ページからHTML/JSモジュールを取得し、画面操作を開始できることを検証。
- `.github/workflows/magnet-stage1-qa.yml`: Draft PRで上記を検証、スクリーンショット保存。
